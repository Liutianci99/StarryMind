# StarryMind（灵感星图）产品需求文档 PRD v1.1

## 1. 产品概述（Product Overview）

### 1.1 产品名称

- 中文名：灵感星图
- 英文名：StarryMind

### 1.2 产品定位

一款基于大模型（LLM）向量语义技术与 3D 视觉交互的独立思维管理微 SaaS（Micro-SaaS）。

### 1.3 核心理念

抛弃传统树状目录与连线式知识图谱的繁琐维护。利用 AI 将碎片化的念头转化为多维向量，在 3D 空间中通过“引力”自动完成相似思维的聚类，形成动态生长的个人灵感星系。

### 1.4 首发平台

移动端优先，跨平台支持，采用混合渲染架构。

## 2. 核心机制与实体定义（Core Mechanisms & Entities）

笔记（念头）在系统中被抽象为“天体”，并由 AI 自动完成实体级别划分。

### 2.1 天体实体分级

| 实体级别          | 判定标准（AI 自动划分）     | 3D 视觉表现                            |
| ------------- | ----------------- | ---------------------------------- |
| 卫星（Satellite） | 字数 < 100 字的碎片闪念   | 体积小，低亮度，在特定行星或恒星的轨道上公转             |
| 行星（Planet）    | 100-500 字的复盘、日志   | 体积中等，带基础自转，颜色受文本情感色彩（Sentiment）影响  |
| 恒星（Star）      | >500 字的深度长文，或高引节点 | 体积最大，作为局部星云的引力中心，带动态光晕（Glow）与呼吸灯效果 |

## 3. 核心更新：向量语义图谱逻辑（Vector Semantic Graph Logic）

本项目不采用基于传统三元组（主谓宾）的知识图谱，而是采用“无感记录，自动引力”的向量图谱机制。

### 3.1 Embedding 转化

- 用户的每一次文本输入，都将在后台通过 `text-embedding-3-small` 等模型转化为高维向量数组。

### 3.2 宇宙物理学计算法则

#### 3.2.1 万有斥力（Repulsion）

- 所有天体在 3D 坐标系中初始拥有相互排斥的力，避免视觉重叠。

#### 3.2.2 语义引力（Semantic Gravity）

- 系统计算两颗天体向量的余弦相似度（Cosine Similarity）。
- 相似度越高，即语义越接近，两颗星之间的引力越大。

#### 3.2.3 星云坍缩

- 当多个语义相近的想法持续输入后，它们会在斥力与引力的动态平衡中自动聚集。
- 最终形成肉眼可见的“星云簇”，并生成发光连线。

## 4. 核心更新：技术架构方案（Hybrid Technical Architecture）

为了兼顾单人全栈开发的敏捷性以及高质量 3D 交互体验，采用 Flutter + WebGL 混合架构。

### 4.1 客户端外壳（Client Shell）

- 技术栈：Flutter（Dart）
- 负责原生 UI 交互，包括底部文本输入框、侧边栏设置与用户状态管理
- 负责数据流转与本地持久化存储

### 4.2 3D 渲染引擎（3D Rendering Core）

- 技术栈：Three.js / WebGL，嵌入 Flutter WebView
- 负责接收 Flutter 传来的坐标与节点数据
- 使用 `OrbitControls` 实现类似 Google Map 的上帝视角交互，包括单指旋转、双指缩放与拖拽平移
- 负责天体发光材质（Shaders）、自转公转动画以及力导向排布的实时渲染

### 4.3 后端与 AI 调度层（Backend & AI）

- 技术栈：Node.js / Supabase（Serverless）
- 作为中转层，调用大模型 API 获取文本摘要、级别划分与向量数据
- 使用 `pgvector` 存储天体向量数据，支持高效相似度检索

## 5. UI/UX 交互规范（Interaction Guidelines）

### 5.1 主界面

- 全屏 3D 星空画布
- 输入框与功能按钮以磨砂玻璃（Glassmorphism）质感悬浮于画布之上

### 5.2 沉浸漫游

- 手势操作画布时不应出现明显卡顿
- 星体保持缓慢自转与微小漂浮感，使宇宙具备“生命力”

### 5.3 节点交互

- Hover 或点击时，通过射线检测（Raycaster）命中天体
- 天体高亮后，弹出浮层（Floating Panel）显示文字摘要

### 5.4 聚焦阅读

- 双击恒星或行星时，触发摄像机平滑推进（Camera Tween Animation）
- 同时全屏展开深色笔记阅读或编辑页

## 6. 第一阶段开发里程碑（Phase 1 Milestone - MVP）

### 6.1 阶段目标

跑通“Flutter 壳 -> WebView 通信 -> 3D 渲染”的最小技术闭环。

### 6.2 MVP 范围

#### 3D 渲染层

- 让 AI 使用 Three.js 编写一个纯前端 HTML 文件
- 实现黑色星空背景、鼠标或手势拖拽视角
- 随机生成 20 个大小不一的 3D 发光球体

#### 容器通信层

- 创建一个 Flutter 项目
- 引入 `webview_flutter` 插件，将上述 HTML 文件作为应用首页
- 跑通 Flutter 点击按钮向 WebView 发送指令的通信逻辑，例如在宇宙中新增一颗星星

#### 交互层

- 在 Flutter 底部实现简单文本输入框
- 输入文字并点击发送后，3D 画布中平滑飞入一颗新天体
- 点击该天体后，可通过 Flutter 弹窗显示对应输入文字

### 6.3 MVP 阶段说明

MVP 阶段可先使用随机坐标替代向量引力计算，优先验证前后端渲染链路与交互闭环。
